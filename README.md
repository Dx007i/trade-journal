# 交易日志管理系统

一个本地运行、开箱即用的股票交易记录管理工具。无需安装 Python 环境，双击即可使用。所有数据保存在你自己的电脑上，不上传任何服务器。

---

## 📦 这是什么

本系统帮你：

- **记录每笔交易**：从券商导出 CSV，一键导入，自动计算手续费（佣金万1、印花税万5）
- **按股票复盘**：查看每只股票的持仓、盈亏汇总
- **按交易日复盘**：查看每笔交易明细，可填写买卖逻辑、打标签、传截图
- **标记与评分**：旗帜标记、点赞/点踩，方便日后回看

> 📌 本系统是单机本地工具，不联网、不推送、不收集任何数据，适合注重隐私的交易者。

---

## 🚀 快速开始

### 1. 启动系统

**推荐方式**：双击 `启动交易日志.bat`

- 自动启动后台服务并打开浏览器
- 启动窗口会自动关闭，服务在后台运行

**备用方式**：双击 `交易日志系统.exe`

- 启动后手动打开浏览器访问 http://127.0.0.1:8897

### 2. 访问界面

启动成功后，浏览器会自动打开（若没有，手动访问 http://127.0.0.1:8897 ）。

界面顶部有四个标签页：

| 标签 | 用途 |
|------|------|
| 按股票查看 | 看每只股票的持仓、盈亏汇总 |
| 按交易查看 | 看每笔交易明细，可编辑逻辑、标签、上传截图 |
| CSV导入 | 导入新的交易记录 |
| 顶部统计栏 | 总交易数、净盈亏、手续费等汇总 |

### 3. 停止系统

双击 `停止交易日志.bat` 即可一键停止后台服务。

> ⚠️ **不要直接删除文件夹来"关闭"系统**，那样后台进程仍在运行。请用 `停止交易日志.bat` 正常停止。

## 📥 导入交易记录

详细说明见 `导入交易/导入说明.txt`，简单三步：

1. 从券商软件导出成交明细 CSV
   - 同花顺 / 通达信 / 东方财富 / 华泰证券等均支持导出
2. 网页点顶部「CSV导入」标签
3. 把 CSV 文件拖进虚线框 → 点「确认入库」

**CSV 格式要求**（表头第一行，列顺序固定）：

```
成交时间,证券代码,证券名称,操作,成交数量,成交均价,成交金额
09:30:15,600000,示例银行,买入,100,10.000,1000.00
14:55:30,000001,示例股份,卖出,300,8.800,2640.00
```

系统会自动识别：

- 文件名中的日期（如 `交易_20260719.csv` → 2026-07-19）
- 文件编码（UTF-8 / GBK 自动识别）
- 买卖方向（买入/证券买入 → 买入；卖出/证券卖出 → 卖出）
- 手续费（佣金万1、印花税万5自动计算）

> 📁 `导入交易/模板_20260719.csv` 是一份格式示例，可直接参考。

## 💾 数据与备份

**你的所有数据都在 `data` 文件夹里**，程序本身不存储任何用户数据：

```
data/
├── trades.json       所有交易明细（不可手动修改）
├── daily_log.json    每日合并日志（含你填写的逻辑/标签/截图）
├── tags.json         标签配置（买入逻辑/止损条件/信息来源等）
└── screenshots/      所有上传的截图
```

### 备份方法

把整个 `data` 文件夹复制到别处即可。

### 恢复方法

把备份的 `data` 文件夹覆盖回来即可。

### 换电脑迁移

把整个「交易日志系统」文件夹拷到新电脑，双击启动即可，数据跟着走。

## 🏷️ 标签管理

你可以为每条交易记录标记以下信息：

- **买卖逻辑**：如"突破前高买入""缩量回调"等（自定义）
- **止损条件**：如"跌破20日线""亏损5%"等（自定义）
- **止盈条件**：如"达到目标价""顶背离"等（自定义）
- **信息来源**：交易思路来自哪里（自定义）
- **旗帜 / 点赞 / 点踩**：快速标记值得回看的交易

标签在「按交易查看」页面填写，标签列表可在前端「标签管理」中自行增删改。

> 💡 首次启动时 `tags.json` 为空示例，你可以按自己的交易体系自由添加。

## ❓ 常见问题

**Q：双击 exe 没反应？**
A：等 5-10 秒，首次启动稍慢。若仍不行，用 `启动交易日志.bat` 启动，会有错误提示。

**Q：浏览器没自动打开？**
A：手动访问 http://127.0.0.1:8897

**Q：提示端口 8897 被占用？**
A：先双击 `停止交易日志.bat` 关掉旧服务，再重新启动。若仍占用，说明有其他程序用了这个端口。

**Q：导入 CSV 后数据没出现？**
A：检查 CSV 表头是否完全匹配（成交时间、证券代码、证券名称、操作、成交数量、成交均价、成交金额），列顺序不能乱。

**Q：手续费算错了？**
A：系统按佣金万1、印花税万5计算（卖出收印花税，买入不收）。如果你的费率不同，导入后可在「按交易查看」中手动编辑 fee/tax 字段。

**Q：怎么升级到新版本？**
A：用新的「交易日志系统.exe」替换旧的即可，`data` 文件夹不要动（保留你的数据）。

**Q：数据会丢失吗？**
A：不会。所有数据存在本地 `data` 文件夹，与程序分离。定期备份 `data` 文件夹即可。
